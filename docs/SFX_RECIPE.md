# РЕЦЕПТ РАБОТЫ С SFX-ЭФФЕКТАМИ НА ЭТОЙ МАШИНЕ (проверено 01.11.2026)

> Документ перенесён из рабочей среды монтажа и обобщён: названия проекта, клипов и людей заменены плейсхолдерами. Проверенные факты и числа сохранены.

Как добывать, обрабатывать и ставить звуковые эффекты. Две независимые
источника: **SFXMint** (CC0, удалённый MCP) и **папка `SFX` заказчика** в папке
исходников (только чтение).

## 1. Источники и что они дают

| Источник | Что это | Лицензия | Ограничения |
|---|---|---|---|
| **SFXMint MCP** | удалённый MCP-сервер `https://sfxmint.com/mcp` (Streamable HTTP, установка не нужна). Реестр MCP: `com.sfxmint/sounds` | **CC0-1.0** — подходит и для внутреннего показа, и для публикации в соцсетях ведомств | без ключа — **20 разных звуков в сутки на сеть**; генерация требует API-ключа |
| **Папка `SFX` в папке исходников** | подборка заказчика: авария, занос, сердцебиение, трасса, набор номера, ожидание трубки, клавиатура iPhone | права заказчика — уточнять перед публикацией | папка исходников — **строго только чтение** |

Приоритет: **звук съёмки → room tone → музыка → синтетические эффекты.**
Эффект из библиотеки — добавка, а не основа (см. `templates/PROJECT_CONTEXT.md` §14).

## 2. Подключение SFXMint к mavis

```json
{ "mcpServers": { "sfxmint": { "url": "https://sfxmint.com/mcp" } } }
```

Через CLI профиля:

```
mavis mcp create name=sfxmint transport=http url=https://sfxmint.com/mcp
mavis mcp list
mavis mcp get name=sfxmint
```

Проверка живости без MCP: `GET https://sfxmint.com/mcp` → **405 Method Not
Allowed**. Это норма: значит сервер жив, нужен POST с JSON-RPC.

### Инструменты (10, из них 5 без ключа)

| Инструмент | Ключ | Назначение |
|---|---|---|
| `search_sounds` | нет | поиск по описанию; при отсутствии полного совпадения — `closest` с `missing_terms` и `library_fit` |
| `get_role_sound` | нет | звук под именованную роль (`impact`, `notification`, …) + 2–3 альтернативы |
| `get_sound` | нет | точные метаданные по slug: формат, SHA-256, акустика, `license`, `page_url` |
| `get_sound_set` | нет | набор под сцену (18 готовых сетов) |
| `studio_list_link` | нет | одна ссылка на Studio для всех недостающих звуков сразу |
| `generate_sound` | **да** | генерация одного эффекта (до 4 вариантов) |
| `generate_ambience` | **да** | 30-секундные эмбиент-подложки |
| `generate_music` | **да** | 30-секундный инструментальный BGM |
| `get_generation` | **да** | опрос готовности генерации |
| `change_sound` | **да** | правка сделанного take (три версии, бесплатно) |

Ключ передаётся заголовком `Authorization: Bearer sfx_live_…`.
**Агент за платные сервисы не платит** — если нужен кредит, решение за заказчиком.

## 3. Прямые вызовы без MCP: `tools/sfx/sfxmint_call.py`

MCP-сервер бывает недоступен из рантайма (или нужно батчем). Тогда — JSON-RPC
напрямую из Python:

```powershell
python tools/sfx/sfxmint_call.py tools
python tools/sfx/sfxmint_call.py call search_sounds '@args.json'
python tools/sfx/sfxmint_call.py batch '@spec.json' --out result.json
```

macOS: те же три команды, тот же файловый аргумент `@args.json`; shell-аналоги — `ls`, `grep`, `cp`, `rm`.

`spec.json` — список `{"tool": ..., "args": {...}}`.

**Грабля:** аргументы с JSON передавать **файлом** (`@путь`), а не строкой
в PowerShell — кавычки в inline-JSON PowerShell съедает, и `json.loads`
падает на `{query:...}`.
macOS: shell тоже съедает кавычки в inline-JSON — правило то же, передавать файлом.

## 4. Поиск: как читать ответ

`search_sounds` возвращает:

| Поле | Что значит |
|---|---|
| `results` | полные совпадения (все слова запроса есть в тексте звука) |
| `closest` | ближайшие, у которых **не хватает слов** — смотри `missing_terms` |
| `library_fit` | `full` / `close` / `weak` / `none` — насколько библиотека покрывает запрос |
| `generate_available` | если точного нет: промпт, `page`, `buy_url`, `mcp_tool` |

**Правила SFXMint, которые нельзя нарушать:**
- `near_matches` **не подменяют** `closest` — это разные вещи;
- `match`/`score` — только ранжирование, а не доказательство;
- если точного совпадения нет — **самому оценить** `closest` по `missing_terms`
  и дать пользователю послушать.

Проверено на сцене аварии: `library_fit: close`, полного совпадения нет,
`closest` = «пустое пластиковое ведро», «камень», «топор» — с
`missing_terms: ['steering', 'wheel']`. Как stand-in это не годится, честно
записано в `LICENSES.md` проекта (формат — `docs/LEGAL_ASSETS.md` §3.3–3.4).

## 5. Скачивание: `tools/sfx/sfxmint_download.py`

```powershell
python tools/sfx/sfxmint_download.py <ПАПКА_SFX>/manifest_crash.json
```

macOS: та же команда, путь к манифесту — POSIX-стилем.

Манифест:

```json
[{ "slug": "impact-thud-63",
   "page_url": "https://sfxmint.com/sounds/impact-thud-63",
   "license": "CC0-1.0",
   "wav_sha256": "d2683379…",
   "use": "роль в ролике" }]
```

Скрипт скачивает `https://sfxmint.com/dl/<slug>.wav?src=mcp`, **сверяет
SHA-256 с метаданными сервера** и пишет отчёт `download_report.json`.

**Хранить `page_url`, не файловую ссылку с `g=`** — подпись в ссылке живёт
48 часов, страница живёт всегда.

**Лимит:** 20 разных звуков в сутки на сеть без ключа. Ответ 429
`download_limit` **не ретраить** — передать заказчику.

## 6. Обработка: `tools/sfx/process_sfx.py`

Стандарт проекта: **48 кГц, стерео, pcm_s24le** (как `audio/proc`,
`audio/voice`). Оригиналы SFXMint — 44,1 кГц / s16 — остаются в
`<ПАПКА_SFX>/orig/`.

Цепочка:

```
aresample=48000:filter_size=64:phase_shift=10
  → highpass=f=35 (удар) | highpass=f=80 (оглушение)
  → lowpass=f=4000…6000 (только для «металлических» вариантов)
  → alimiter=limit=0.891251:attack=5:release=50:level=disabled
  → volume=<добор до цели>  (итеративно, до 4 проходов)
```

Потолки: удары **−1,5 dBTP**, оглушение **−6,0 dBTP**.

**Грабля:** `alimiter` по умолчанию включает auto-level (`level=auto`) —
без `level=disabled` файл будет нещадно выровнен. `alimiter` ограничивает
**сэмплы**, а не true peak: у низкочастотного удара true peak на ~0,5 дБ
выше сэмплового, поэтому порог достигается итеративно.

### Замеры (обязательны)

| Что | Чем |
|---|---|
| true peak | `ffmpeg -af ebur128=peak=true -f null -`, поле `Peak:` |
| RMS, клиппинг, центроид | numpy по `pcm_s16le` 48 кГц (`pcm_stats` в `tools/sfx/process_sfx.py`) |
| активная часть | окна 40 мс выше «максимум − 35 дБ» |
| хвост | RMS последних 200 мс (щелчок на стыке) |

`ebur128` **не отдаёт RMS** в summary — считать самому.

**Методика центроида:** считать по активной части. По всей длительности
тихий хвост тянет центроид вверх в 10–12 раз (для `impact-thud-63`:
1 085 Гц против 130 Гц у SFXMint — у них своя выборка). Для сравнения
«до/после» обе величины считать одним кодом.

Чужие файлы (папка `SFX` заказчика в папке исходников) мерять тем же кодом —
`tools/inventory/measure_sfx.py` — иначе сравнение нечестное.

## 8. Грабли Resolve (проверено 01.11.2026)

| Грабля | Симптом | Что делать |
|---|---|---|
| **`ImportMedia` на WAV 24 бит** | Resolve уходит в 100 % CPU и **не отвечает на API** минутами; `Responding: False`, при этом процесс жив | не паниковать и не перезапускать сразу: сначала проверить, растёт ли CPU (`Get-Process Resolve`). Импорт тяжёлый. Если нужен перезапуск — проект уже сохранён (`pm.SaveProject()`) и выгружен в `.drp` |
| `ImportMedia` возвращает пустой список | импорт при этом может пройти | проверять результат не по возврату, а по `GetRootFolder().GetClipList()` |
| **`Timeline.GetMarkers()`** | в 21.1.1 возвращает **dict** `кадр → {name, note, color}`, а не список | `list(mk)` даст только кадры — имена теряются. Читать `mk[frame]["name"]` |
| `tl.GetMarkerList()` | отсутствует (вернёт `None`, а `None` не callable → исключение) | использовать `GetMarkers()` |
| `TimelineItem.GetName()` на видео | падает «'NoneType' object is not callable» на части айтемов | читать имя из `GetMediaPoolItem().GetName()` |
| `MediaPoolFolder.GetClipCount()` | отсутствует | `len(folder.GetClipList())` |
| PowerShell `>` | пишет UTF-16 | писать файлы из Python (`encoding="utf-8"`) |
| `Copy-Item`/`Remove-Item` по маске | блокируется политикой | `shutil` из Python |

**macOS:** `Get-Process Resolve` → `ps aux | grep Resolve`; `Copy-Item`/`Remove-Item` →
`cp`/`rm` (или `shutil` из Python); shell-редирект `>` пишет UTF-8 — правило
«писать файлы из Python» остаётся.

## 9. Куда ставить на таймлайн

Приоритет: отдельная **аудиодорожка SFX** (в проекте — A4), чтобы её можно
было сдвинуть или снять одним движением, не трогая остальной монтаж.

Вставка — только явными кадрами:

```python
tl.AddTrack("audio")                      # -> A4
tl.SetTrackName("audio", 4, "SFX · АВАРИЯ")
mp.AppendToTimeline([{
    "mediaPoolItem": item,
    "recordFrame": 94364,                 # точка на таймлайне
    "trackIndex": 4,
    "mediaType": 2,                       # только аудио
}])
```

`AppendToTimeline` при коллизии **не перезаписывает, а сдвигает и обрезает**
— всегда сверять `GetStart()`/`GetEnd()`/`GetDuration()` вставленного айтета.

После вставки — структурная проверка: `python tools/verify_timeline.py`
(карта дорожек, длительности, gaps/overlaps) и спот-чек маркеров.
macOS: та же команда, путь через `/`.
